## 判定: 犯人は「空 past に対するソフトプロンプト」

単離マトリクス(`greeting_isolation.py`、temp 0.6、"Hello"):

FFT 重み・think 強制・ベースモデルは全て無罪。**唯一の変数は SP の有無**。

メカニズム: pooler は数学 CoT 文脈のみで学習されているため、**空入力から生成される
32 ベクトルは「数学の問題が存在する」という恒常バイアス信号**になっている。初回ターンは
rw の間ずっと kept が空なので、全ての初回ターン(挨拶含む)の先頭にこのバイアスが注入され
ていた。「12.」や統計講義は、このバイアスに従ってモデルがタスクを発明した結果である。
(以前「曲がりなりにも動いた」のは、バイアスに逆らうサンプルを引いた時 — 確率的だった。)

## 修正(1 行のガード・アーキテクチャ的に正しい)

```
kept(吸収済み distant バッファ)が空の間は、SP ブロックを前置しない(pooler を呼ばない)。
kept が非空になったら従来どおり [SP + recent]。
```

「無の要約」には情報がなく、学習バイアスだけが乗る — 注入しない以外の正解はない。
正典実装: `app_session_torch.py` の defect #16 コメント周辺。
**production の `sp_mlx.generate_sp` / `tiered_rag_mlx.ChatSession`(現在は常時前置)と
